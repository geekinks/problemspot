# Changelog

Notable user-facing and contributor-facing changes will be recorded here.

## Unreleased

### Added

- Initial Next.js application shell and brand assets.
- Product requirements and architecture documentation.
- Contributor, security, governance, validation, moderation, privacy, testing,
  deployment, and Solution Lab guidance.

### Changed

- Repositioned ProblemSpot around human-led problem validation and open-source
  missions.
- Restricted AI and coding-agent assistance to the optional, post-validation
  Solution Lab.

## Release format

For each release, group changes under `Added`, `Changed`, `Fixed`, `Security`,
and `Removed` where applicable. Link the release tag and migration notes. Do
not include private vulnerability details before coordinated disclosure.
