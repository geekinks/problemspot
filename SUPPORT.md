# ProblemSpot Support

Choose the channel that matches your need.

| Need | Channel |
|---|---|
| Setup or usage question | [GitHub Discussions](https://github.com/geekinks/problemspot/discussions) |
| Reproducible bug | [Bug report](https://github.com/geekinks/problemspot/issues/new?template=bug_report.yml) |
| Product improvement | [Feature request](https://github.com/geekinks/problemspot/issues/new?template=feature_request.yml) |
| Community use case | [Community problem template](https://github.com/geekinks/problemspot/issues/new?template=community_problem.yml) |
| Security vulnerability | [Private security advisory](https://github.com/geekinks/problemspot/security/advisories/new) |

Before asking for help:

1. Read [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
2. Search existing issues and discussions.
3. Include the command, expected result, actual result, environment, and a
   minimal reproduction when relevant.
4. Remove access tokens, private evidence, personal information, and exact
   residential locations.

ProblemSpot is community-maintained. Response times are not guaranteed. Please
do not privately contact individual contributors unless they have explicitly
offered that support channel.
